## Agent skills

### Issue tracker

Issues are tracked in this repo's GitHub Issues, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Bar entry and panel

This plugin is the sibling of `com.aeonarc.delux-m900` (`~/.config/omarchy/plugins/com.aeonarc.delux-m900/`): the bar glyph (the mouse), the panel layout and its wording follow the M900. For clicks, label and settings, read `/usr/share/omarchy/shell/plugins/bar/README.md` ("Icon geometry") and the shell's battery widget, `/usr/share/omarchy/shell/plugins/panels/power/Panel.qml`.

### Live test

Before trying a change on the running bar or the real mouse, read `docs/agents/live-test.md`.
